# ZEX

> ZEX —— 本地游戏、影视、音乐三合一库管理工具，数据全在本机。

[![Version](https://img.shields.io/badge/version-v0.1.0-blue)](https://github.com/Yuzexiaoyu/Zex)

ZEX 是一款装在自己电脑上的游戏、影视、音乐三合一管理工具。所有数据都存在本机，不用联网也能用，完全由你自己掌控。

## ✨ 功能特性

### 🎮 游戏库

- **Steam 一键导入**：自动扫描本机已安装的 Steam 游戏，点一下全部入库；手动添加任意游戏也可以
- **自动封面**：自动获取游戏封面海报，列表整整齐齐
- **游玩时长**：自动记录每个游戏的游玩时长，随时可查
- **帧数显示与限帧**：可在屏幕角落显示帧数（画面每秒刷新次数），也可限制帧率上限让画面更稳定；NVIDIA 显卡还能开启低延迟模式，操作更跟手

### 🎬 影视库

- **内置播放器**：开箱即用，不用安装任何额外软件
- **高画质支持**：4K 高清、高压缩效率格式（同画质占空间更小）、HDR 高动态范围直通、杜比视界调色映射（普通屏幕也能还原接近原片的色彩）、特效字幕
- **自动连播**：剧集播完自动接下一集，追剧不用手动点
- **记忆进度**：自动记住看到哪一集、哪一分钟，下次打开接着看
- **自动封面**：影视海报自动获取，海报墙赏心悦目

### 🎵 音乐库

- **桌面歌词**：播放音乐时在桌面显示歌词，边干活边看词很方便

### ⚙️ 全局体验

- **托盘驻留**：最小化到系统托盘，后台照常记录时长，随时唤回
- **开机自启**：可安静地驻留托盘不弹窗，启动无打扰
- **手柄操控**：Xbox 手柄与 PS5 手柄可全程操作——方向键导航、按键确认、一键切换库，沙发上也能掌控
- **深浅色主题**：自动跟随系统，白天夜晚都舒服
- **备份恢复**：数据一键导出备份、一键导入恢复，换机或重装系统都不怕丢
