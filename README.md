ZEX：你的本地游戏、影视、音乐管家
ZEX 是一款装在自己电脑上的游戏、影视、音乐三合一管理工具。所有数据都存在本机，不用联网也能用，完全由你自己掌控。
游戏库
一键导入 Steam 游戏：自动扫描本机已安装的 Steam 游戏，点一下全部入库；手动添加任意游戏也可以
自动获取封面海报，游戏列表整整齐齐、一眼看过去很舒服
自动记录每个游戏的游玩时长，想知道某个游戏玩了多少小时，随时能查
可以给单个游戏或所有游戏开启屏幕角落的帧数显示（也就是画面每秒刷新的次数），还能把帧率限制在一个上限，让画面更稳定、更省资源；NVIDIA 显卡用户还可以开启低延迟模式，操作响应更快、更跟手
影视库
内置播放器开箱即用，不用另外安装任何软件
支持 4K 高清、更高效率的压缩格式（画质一样好、文件占得更少）、HDR 高动态范围画面直通、杜比视界调色映射（在普通屏幕上也能还原接近原片的色彩），以及各种带特效的样式字幕
剧集自动连播，一集播完自动接下一集，追剧不用手动点
自动记住看到哪一集、哪一分钟，下次打开接着看
影视封面自动获取，海报墙赏心悦目
音乐库
播放音乐时可以在桌面显示歌词，边干活边看词很方便
全局体验
最小化到系统托盘后，后台照常记录时长，想用时随时唤回
支持开机自启，可以安静地驻留托盘、不弹窗打扰
支持 Xbox 手柄和 PS5 手柄全程操作：方向键导航、按键确认、一键切换库，坐在沙发上也能轻松掌控
界面深浅色自动跟随系统，白天夜晚都舒服
数据支持一键导出备份、一键导入恢复，换电脑或重装系统都不怕丢
ZEX 就是一个本地、隐私、省心的三合一媒体管家，让游戏、影视、音乐各归其位。
