# 2026-11-01

## 统计页首次进入「微加载」排查与修复

**现象**：首次切到统计页有一次可见的加载感；游戏库/影视库/音乐库首次进入都很丝滑。

**根因（4 条，按代价排序）**
1. `StatsView` 的 `useEffect(..., [active])` 每次进入都 `loadStats()`：IPC 回包 + `set({stats})` 换新对象，导致每列最多 500 行、三列合计 1500 行全部重渲染，正好压在切页那一帧。对比 `GameView` 是 `useEffect(..., [])` 只挂载时加载 —— 这是「其他库丝滑」的直接原因。
2. `imagesReady` 当整页门禁：未就绪时 `.stats-page` `visibility: hidden` + `StatsPlaceholder` 骨架覆盖，`READY_TIMEOUT_MS = 1500`。就绪前进入 → 看到灰骨架 → 骨架卸载 + 内容出现，就是「微加载」。
3. 统计页全量 `top.map` 渲染所有行（后端每列 `LIMIT 500`），而行是固定高度（88px = 封面 72 + padding 14 + border 2）。`GameGrid` 用 `@tanstack/react-virtual` 只渲染可见行 + overscan 3。
4. `preloadStatsImages` 的 effect 依赖 `[stats, hasData, hiddenLibraries]`，stats 换对象就重建 ResizeObserver 并重跑几何遍历 + decode；`data-stats-enter` 每次 active 都重播 0.3s `card-enter`（opacity 0 起）。

**改动**
- `src/views/StatsView.tsx`
  - 进入刷新改为延后 320ms + 5s 节流（`lastLoadRef`，初值 = 挂载时刻）；首屏无数据时仍立即补。
  - 删除 `imagesReady` 整页门禁与骨架覆盖，真实结构直接可见，未就绪封面由 `.stats-row-cover` 底色兜底。
  - `preloadRef` 保证预热只建立一次，卸载时统一 dispose。
  - `entered` state 让 `data-stats-enter` 常驻，切走切回不重播入场动画。
  - `ColSection` 的 `ready` 从 `active && imagesReady` 改为 `active`（手柄不等图片）。
- `src/components/StatsCovers.tsx`：`RowCard` 增加按值 memo 比较（id/name/sub/seconds/count/wide_path/cover_path/media/color/rank/focused/anchor/onContextMenu），stats 换对象时内容没变的行整块跳过。
- `src/index.css`：`.stats-row` 加 `content-visibility: auto` + `contain-intrinsic-size: auto 88px`，屏外行跳过布局与绘制。
- `src/utils/statsPreload.ts`：`READY_TIMEOUT_MS` 1500 → 400。

**验证**：`npx tsc --noEmit` 通过；`npx vite build` 通过（dist 已更新）。

**仍可优化**：`.stats-col` 三块全高 `backdrop-filter: blur(16px)` 是首帧 raster 的剩余开销，若仍觉顿可降级为半透明纯色。

## 发布：出 zip + 单独替换 F 盘 exe（不动 data）
